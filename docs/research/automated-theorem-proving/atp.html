증명 상태, 전제, tactic

작은 Lean 4 예제

example (n : Nat) : n + 0 = n := by
  exact Nat.add_zero n

설명용 예제. 브라우저에서 Lean을 실행하지 않습니다.

Proof state
현재의 가정과 남은 증명 목표
n : Nat ⊢ n + 0 = n
Premise
사용할 수 있는 정리·정의
Nat.add_zero
Tactic
증명 상태에 적용할 명령
exact Nat.add_zero n

실제 문제에서는 tactic 하나로 끝나지 않아, 여러 후보와 중간 상태를 탐색합니다.

검색한 정리를 사용하는 예

현재 상태

⊢ n + 0 = n

03 / InternLM2.5-StepProver

critic을 활용한 경로 선택

Wu et al. / 최초 공개 2024 / 읽은 버전: v2, 2025

Prover

증명 상태·이전 tactic 문맥을 보고
다음 tactic 후보를 생성합니다.

Lean

후보를 실행해 유효성을 확인하고
새 증명 상태를 만듭니다.

Critic

중간 상태에 점수를 주고
다음에 탐색할 상태를 고릅니다.

학습 신호

성공 경로에서 상태의 선호 관계를 추출합니다.
탐색·재학습을 expert iteration으로 반복합니다.

critic 점수는 탐색 우선순위입니다. 증명의 정당성은 Lean이 검사합니다.

다음에 확장할 상태의 우선순위

후보 생성 이후에도
어떤 상태부터 볼지 결정해야 합니다.

  1. 01상태 A후보 경로 A의 중간 상태
  2. 02상태 B후보 경로 B의 중간 상태
  3. 03상태 C후보 경로 C의 중간 상태

생성한 tactic의 확률 정보를 활용해 상태 A를 먼저 확장합니다.

설명용 순서 예시입니다. 실제 모델 점수·실험 데이터가 아닙니다.

탐색 방식에 따른 성공률

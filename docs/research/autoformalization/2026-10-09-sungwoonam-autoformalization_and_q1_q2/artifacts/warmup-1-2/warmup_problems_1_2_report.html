Executive Summary

Warm-up problems 1 and 2 both proved list subset lemmas over syntax tree traversals. In both original proofs, repetitive structural induction boilerplate was written manually: the author handled 8+ AST cases individually, frequently performing manual variable renamings (rename_i), destructing membership hypotheses across appended lists, and manually applying transitivity and list append lemmas (List.Subset.app, List.Subset.trans).

Both proofs were refactored into high-level automated proofs using induction, targeted unfolding, case splitting, automatic simplification (simp_all, simp +contextual), and combinator repetition. Crucially, both refactored proofs remain purely constructive, preserving the exact same standard axiom footprint ([propext, Quot.sound]) without introducing non-constructive axioms (Classical.choice) or any external dependencies, while achieving an 86% to 88% reduction in proof size.

Problem 1: CallElimCorrect.substOldPostSubset

Theorem Statement

open OldExpressions in
theorem substOldPostSubset:
  (Imperative.HasVarsPure.getVars (P:=Expression)
    (substOld h2 (Lambda.LExpr.fvar m h1 ty) post)).Subset
    (Imperative.HasVarsPure.getVars (P:=Expression) post ++ [h1])

Diagnostic & Root Causes of Inefficiency

  • Repetitive Case Handlers: 9 separate case branches (fvar, op, const, bvar, abs, ite, app, quant, eq) that basically performed identical reasoning.
  • Fragile Tactic Plumbing: Extensive use of positional rename_i and dummy simp at ... calls on arbitrary variables.
  • Manual List Subset Splitting: In every recursive branch, List.Subset.app and List.Subset.trans were chained manually up to 3 times per case, followed by identical simp_all; cases Hin <;> simp_all routines.

Refactoring Strategy

Unfold substOld across the induction, perform standard try split to unfold the inner match of substOld on application nodes, simplify definitions with simp_all, repeat apply List.Subset.app with List.Subset.trans, and discharge residual membership obligations with simp +contextual [List.Subset, or_imp].

Problem 2: CallElimCorrect.extractedOldExprInVars

Theorem Statement

open OldExpressions in
theorem extractedOldExprInVars :
  NormalizedOldExpr post →
  (extractOldExprVars post).Subset
  (Imperative.HasVarsPure.getVars post)

Diagnostic & Root Causes of Inefficiency

  • Inducting on the Wrong Object: The original proof did induction post and then destructed Hnorm : NormalizedOldExpr post within almost every branch (case app, case abs, case quant, case ite, case eq).
  • Contradiction Proving for Impossible Cases: The original had an 11-line manual derivation (cases Hnorm ... exfalso ... specialize Hn ... constructor ... apply Hfalse ... rfl) to refute the unnormalized branch in extractOldExprVars.
  • Redundant Transitivity Chaining: As in Problem 1, List.Subset.app and List.Subset.trans were manually chained for all recursive AST variants.

Refactoring Strategy

Induct directly on the inductive derivation h : NormalizedOldExpr post instead of on the raw expression syntax. This immediately provides the exact valid inductive constructors, automatically eliminates malformed AST states, and provides direct access to the normalized subterms. The remaining subset obligations are discharged uniformly using combinators and contextual simplification.

Original Proof (77 lines, 83 tactic calls)

  induction post <;>
    simp [Imperative.HasVarsPure.getVars, extractOldExprVars,

  case app fn e fn_ih e_ih =>
    unfold extractOldExprVars
    split

      intros x Hin
      exact Hin

      | app H1 H2 Hn =>
      exfalso
      specialize Hn ?_
      constructor
      cases Hn
      apply Hfalse
      rfl

      | app H1 H2 Hn =>

      . apply List.Subset.trans
        apply fn_ih
        exact H1
        intros x Hin
        simp_all

        apply e_ih
        exact H2
        intros x Hin
        simp_all
  case abs ih =>
    cases Hnorm
    apply ih <;> assumption

    rename_i e_normalized
    rename_i tr_normalized

    apply List.Subset.app
    . apply List.Subset.trans
      apply trih <;> assumption
      intros x Hin
      simp_all
    . apply List.Subset.trans
      apply eih <;> assumption
      intros x Hin
      simp_all

    cases Hnorm
    apply List.Subset.app
    . apply List.Subset.trans

      intros x Hin

Refactored Proof (5 lines, 12 tactic calls)

    simp_all [Imperative.HasVarsPure.getVars, Lambda.LExpr.LExpr.getVars] <;>
    (repeat' apply List.Subset.app) <;> (try (apply List.Subset.trans; assumption)) <;>
    simp +contextual [List.Subset]

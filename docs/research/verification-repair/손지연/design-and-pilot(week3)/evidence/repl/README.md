# 작은 REPL 예제

## 환경과 실행

Lean 4.19.0 · community REPL v4.19.0에서 정상·오류·수정·sorry 후보와 tactic 상태 전이를 실행했습니다. 모델·Mathlib는 사용하지 않았습니다. 측정일은 원시 요약에 없어 미상으로 남깁니다.

## 오류와 수정

`h : P ∧ Q`에서 `Q ∧ P`를 보일 때 첫 목표는 `Q`입니다. 오류 후보는 `exact h.1`로 P의 증거를 넘겼고, 수정 후보는 `exact h.2`를 사용했습니다. CLI 종료 코드는 정상 0·오류 1·수정 0·sorry 0이었습니다.

12개 REPL 요청으로 다음을 확인했습니다.

- 프로세스 종료 코드 0은 개별 요청이나 증명의 성공을 보장하지 않습니다.
- `goals = []`여도 sorry가 남을 수 있습니다. 필드 부재는 빈 목록과 구분합니다.
- proof state 완성이 원래 environment의 선언을 교체하지는 않습니다.
- 전체 선언을 다시 조립·검사한 `and_swap`은 공리에 의존하지 않았습니다.

## 결과와 보관 범위

[results.json](results.json)에 환경·CLI 측정값·12개 요청별 판정·goal 유무·주요 진단을 정리했습니다. 원본 Lean 파일·실행기·프로토콜·로그는 삭제했습니다. 같은 환경과 예제 구현을 별도로 준비해야 재실행할 수 있으며, 이번 정리에서는 실행하지 않았습니다.

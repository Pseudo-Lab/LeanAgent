1. 개인별 자료는 해당 폴더에 `YYYY-MM-DD-name-topic.md`로 작성합니다. 발표자료·예제는 같은 이름의 하위 폴더에 함께 보관할 수 있습니다.
2. 폴더 README의 공유 자료 표에 작성한 파일 또는 외부 발표자료 링크를 추가합니다.

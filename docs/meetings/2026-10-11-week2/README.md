- PDF / 인쇄 버튼은 모든 슬라이드를 출력합니다. 화면 공유 전 발표자 노트를 닫습니다.
- 증명 상태와 탐색 우선순위의 클릭 예시는 설명용입니다. 브라우저에서 Lean이나 논문의 모델을 실행하지 않습니다.

# LeanAgent Week 3

2026년 10월 18일 일요일 20:00–22:00.

## 이번 주 목표

[Week 2 논의](../2026-10-11-week2/README.md#주요-논의-사항)를 바탕으로, 증명 리팩터링 에이전트를 구조·전략 설계, 검증·수리, 실행관리·평가·재현의 세 영역으로 나누어 살펴봅니다. 각 그룹은 관심 있는 접근법을 자유롭게 실험하고, 시도한 내용과 발견한 점을 공유합니다.

## 이번 주 역할 분담

아래 주제를 중심으로 함께 실험합니다. 그룹 내 세부 분담과 실험 방식은 자유롭게 정합니다.

| 담당 영역 | 담당자 | 살펴볼 내용 |
| --- | --- | --- |
| 구조/전략(tactic) 설계 | 박채원, 박선영, 박성호 | 기존 증명 분석과 리팩터링 후보를 만드는 전략 |
| 검증/수리 설계 | 남성우, 손지연 | 후보 증명 검증과 실패 원인을 바탕으로 한 수정 방법 |
| 실행관리/평가/재현 | 정소미, 권주원 | 실험 실행, 결과 비교와 재현 방법 |

## 함께 이야기할 내용

- 어떤 Warm-up 문제와 접근법으로 실험했는지.
- 실험에서 잘된 점과 막힌 점, 더 확인해 보고 싶은 것.
- 결과를 비교하거나 다시 실행할 때 고려할 점.
